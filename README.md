Pokedex desarrollado en ASP.NET. Usando la API  pokeapi.

Pokedex web interactivo con un diseño retro que permite buscar, filtrar y explorar información sobre Pokémon, además de exportación de datos a Excel y envío por correo

Este proyecto es el Backend de la aplicación PokeApp
Funcionalidades Principales:
-Endpoints RESTful para listar, detallar y filtrar Pokémon.
-Lógica de negocio del lado del servidor, incluyendo filtrado por nombre y especie.
-Funcionalidades adicionales como exportación de datos a Excel y envío de correos con adjuntos.
-Habilidades de pokemon, stats, tipo, habilidades, evoluciones y formas.
